{% translate "Condiciones de uso" %}

{% translate "En palabras simples: qué pasa con lo que aportas a Ojo Avizor." %}

{% translate "1. Lo que aportas sigue siendo tuyo" %}

{% translate "Cada avistamiento, fotografía y nombre común que registras es un aporte tuyo y de la comunidad de observadores de Pijao. La autoría de ese contenido es permanente: nunca se transfiere, se reasigna ni se anonimiza." %}

{% translate "2. Quién puede usar esos datos, y para qué" %}

{% translate "La Fundación Smurfit Westrock Colombia, la universidad y quien desarrolla esta plataforma pueden usar la información del inventario para los fines del proyecto: construir el catálogo, elaborar la documentación académica y, en el futuro, fines educativos relacionados." %}

{% translate "Usar no es lo mismo que ser dueño: en ningún caso esas organizaciones adquieren la autoría de tu aporte." %}

{% translate "3. Tu identidad" %}

{% translate "En público, tus aportes se muestran con tu seudónimo. Tu nombre real y tu correo nunca se publican; solo los puede ver un Revisor o un Administrador, y únicamente para gestionar la plataforma." %}

{% translate "4. La ubicación exacta no se publica" %}

{% translate "Si registras coordenadas, se guardan completas pero nunca se muestran en público — solo el lugar en texto. Es una medida para no facilitar la localización de especies vulnerables." %}

{% translate "5. Solo fotos propias o con autorización" %}

{% translate "Las fotografías que subas deben ser tuyas o contar con autorización de quien las tomó. No se publica material tomado de internet." %}

{% translate "6. Todo pasa por revisión" %}

{% translate "Ningún aporte se publica sin que un Revisor lo apruebe. Si te devuelven un registro, siempre viene con un motivo explicado — se conserva, no se elimina — y puedes corregirlo y reenviarlo." %}
